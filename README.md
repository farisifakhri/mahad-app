# SIPMA

Sistem Informasi Pembinaan Mahasantri — Mabna Syekh Nawawi,
Ma'had Al-Jami'ah UIN Syarif Hidayatullah Jakarta.

Laravel 12 · PHP 8.3+ · MySQL 8+ · Filament 4 · Blade + Alpine.js.

Lihat [BASELINE.md](BASELINE.md) untuk setup, akun demo, struktur file,
batas implementasi dan hasil verifikasi.

```powershell
php artisan serve
```

Setelah instalasi dan build sesuai panduan, buka http://127.0.0.1:8001.
Panel internal: `/admin`. Portal eksternal: `/login`.
